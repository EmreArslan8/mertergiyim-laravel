# Eski PostgreSQL yardımcı sorguları

Bu klasördeki `.sql` dosyaları önceki Supabase/PostgreSQL kurulumu için
hazırlanmış tek seferlik bakım sorgularıdır. Alwaysdata MariaDB üzerinde
çalıştırılmamalıdır.

Alwaysdata kurulumu ve şema güncellemeleri için yalnızca Laravel migration
zincirini kullanın:

```bash
php artisan migrate --force
```
